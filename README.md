# 🎓 CampusX Data Science Mentorship Program (DSMP 1.0)

This repository contains all my notes, projects, and assignments from the **CampusX Data Science Mentorship Program (DSMP) 1.0** — a complete end-to-end journey from Python programming to Machine Learning.

---

## 📘 Overview

The **CampusX DSMP 1.0** program is a structured, mentor-led course that helps learners build strong foundations in:
- Python Programming
- Statistics & Mathematics for Data Science
- SQL & Data Analysis
- Machine Learning and Model Deployment

This repository is organized according to each major module covered in the program.

## 🧠 Topics Covered

### 🐍 Python Programming
- Basics, Data Types, Loops, Functions, OOP, File Handling  
- Exception Handling, Modules, and Libraries  

### 📊 Python Libraries
- **NumPy** — Arrays, Broadcasting, and Vectorization  
- **Pandas** — DataFrames, Cleaning, GroupBy, Merging  
- **Matplotlib & Seaborn** — Data Visualization  
- **Plotly & Dash** — Interactive Dashboards  

### 📈 Mathematics & Statistics
- Linear Algebra, Probability Distributions, Bayes Theorem  
- Mean, Median, Variance, Standard Deviation  
- Correlation, Hypothesis Testing, and ANOVA  

### 🧩 SQL & Databases
- CRUD Operations, Joins, Subqueries, Aggregations  
- Views, Transactions, and Integration with Python  

### 🔍 Data Analysis
- EDA with Real-World Datasets  
- Data Cleaning, Feature Engineering, Outlier Detection  
- Storytelling with Data Visualization  

### 🤖 Machine Learning
- Linear & Logistic Regression  
- Decision Trees, Random Forests, KNN, Naive Bayes  
- Model Evaluation Metrics (RMSE, R², Accuracy, AUC)  
- Regularization, Feature Selection, Cross-Validation
